# Data profile

**Status: TBD (week 2).**

This document will record what the raw data actually looks like, measured rather than
assumed:

- row counts per month and per file layout
- confirmed CSV encoding and separator
- null rates per column, especially `VL_QUOTA` and `VL_PATRIM_LIQ`
- duplicate rates on the ADR-002 grain
- distribution of quota day-over-day changes, used to calibrate the anomaly rule
- distribution of average net assets, used to set the scorecard eligibility threshold
- how many funds use the legacy layout and over which period
